# Overlooked Connect UI - Reference List

This reference list consolidates key external sources used in the implementation
of the Overlooked Connect Public Web and Internal Web applications. In-text
citations are also retained within relevant source files to identify the
implementation concepts to which individual sources apply.

## Existing Public Web Sources

The Public Web implementation contains additional in-text references and a
source-specific reference list within the relevant CSS and JavaScript files.
